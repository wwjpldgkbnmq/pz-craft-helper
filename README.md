## Overview

Project Zomboid Craft Helper adds a searchable in-game crafting encyclopedia to Project Zomboid, displaying every recipe's required ingredients, skill level prerequisites, and which books teach each recipe. A shopping list feature tracks which missing ingredients the player still needs to collect before a recipe becomes available.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Project Zomboid Craft Helper** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Recipe Browser** | Search all crafting recipes including those learned from skill books |
| **Skill Requirements** | Displays required skill level and associated profession for each recipe |
| **Ingredient Tracker** | Shopping list of missing ingredients needed to complete target recipes |
| **Book Index** | Shows which crafting book teaches each locked recipe in the database |
